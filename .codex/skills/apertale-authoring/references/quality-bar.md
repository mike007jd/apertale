# Apertale minimum checks and requested polish

The live `get_project_context(detail: "authoring-guide")` contract defines the default completion and two-round repair policy. Read it before sketch review and reuse it through generation.

## Default completion

1. Let import/create enforce file type, size, dimensions, real alpha, asset roles and existence, complete-book limits, document revision, and undo safety. Use verified inline results directly; read assets only after a fallback drawer transfer.
2. Present the dedicated cover and every spread once in the current theme. Inspect those actual frames for missing/wrong images, severe subject or text occlusion, photo identity errors, and unreadable or broken pages. Reuse a frame already confirmed at the same revision.
3. When a material failure is visible, replace only the affected asset or patch the affected spread, preserving accepted work. Recheck changed surfaces only, within two repair rounds. Report any remaining blocker and retain the saved book.
4. Deliver when those minimum checks pass. Report actual evidence and stage timings; keep unmeasured values marked unavailable. A successful tool call proves saved state, while a confirmed visible frame proves presentation.

For keyed cutouts, accept real alpha verified by the existing import/create path. A rectangular matte, missing subject, or damaged identity that prevents normal reading calls for local repair. Small aesthetic imperfections can remain for requested polish.

## Explicitly requested polish

When the reader requests a full review, read `get_project_context(detail: "quality-review")`, begin the critique round, inspect its required frames, and record every visual rubric criterion once with located evidence. Inspect both themes only when requested. Keep narrative, style consistency, nuanced alpha edges, animation polish, and sample-level appeal in this review. Complete at most two critique rounds and report remaining findings.

Publication remains a separate reader action. Complete-book delivery uses the minimum checks above rather than a publication-readiness report.
